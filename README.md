## 数据口径

- 信息获取时间：2026-10-08（北京时间）
- 评分：10 分制主观共识分，综合官方计费与配额文档、开发者社区实测反馈与第三方横测；维度为免费额度含金量、价格透明度与竞争力、冷启动与并发上限、生态集成（触发器 / API 网关 / 可观测）、运维与文档完备度，跨品类不宜直接横向比较
- 免费额度：区分「长期免费层」（如华为云 FunctionGraph 每月 100 万次请求、AWS Lambda 中国区宁夏区域的永久免费层）与「限时试用」（如阿里云 FC 的 180 元试用额度、腾讯云 SCF 的前 3 个月额度）
- 价格：国内人民币；海外 USD 原值并按 1 USD≈7.1 CNY 约合（量级参考），欧元档先按 €1≈$1.08 折美元再换算
- 所有价格与免费额度均以官方计费页为最终依据，无法核实一律标「待确认」，未作推测填补
- 价格散点图横轴为「最低付费月费」（按量计费、无月最低消费记为 0），故 0 点表示无月费门槛，不等于完全免费

## 快速结论

- 国内第一梯队：阿里云函数计算 FC（8.9）、腾讯云云函数 SCF（8.8）、亚马逊云科技 Lambda 中国区（8.7）、华为云 FunctionGraph（8.5）、火山引擎函数服务 veFaaS（8.4）
- 海外第一梯队：AWS Lambda（9.0）、Cloudflare Workers（8.9）、Google Cloud Run functions（8.8）、Google Cloud Run（8.7）、Azure Functions（8.6）
- 免费层呈两极分化：华为云 FunctionGraph、AWS Lambda 中国区、三家海外云厂为长期免费层；阿里云 FC、腾讯云 SCF、百度智能云 CFC 为限时试用
- 计价模型碎片化：仅 AWS Lambda、Azure Functions、Microsoft/AWS 传统口径与 Google Cloud Run functions 维持「请求 + GB-秒」两段式；阿里云 FC 与天翼云函数计算用 CU 折算，京东云与火山引擎按 vCPU·秒 + 内存·秒拆分，Netlify 折算为积分，Render 与 Railway 按实例常驻计费
- 边缘函数是唯一仍在扩张免费额度的分支：阿里云 ESA 边缘函数免费版每天 10 万次请求、腾讯云 EdgeOne 免费套餐每月 300 万次执行 + 300 万毫秒 CPU、Cloudflare Workers 免费版每天 10 万次请求、Fastly Compute 免费层每月 1000 万次 Compute 请求

## 重要纠错（已核验）

- **火山引擎函数服务**已于 2024-05-11 下线新用户试用资源包，新用户首次开通不再提供免费额度（官方产品变更公告）
- **Netlify** 自 2026-04-14 起全面改为积分制计费，旧版「每月 12.5 万次函数调用」的免费额度口径已废止；现行 Free 档为每月 300 积分硬上限
- **Fly.io** 自 2024 年 10 月起不再为新账户提供永久免费层，仅保留免费试用（存量老账户权益保留）
- **Heroku Free Dynos** 已于 2022-11-28 停服，作为海外免费层收缩的对照条目列出，不参与评分
- **UCloud（优刻得）、青云、金山云、网易数帆**在本轮公开检索中均未发现独立在营的函数计算 / FaaS 产品线与计费文档，按「不存在（未检索到）」处理
- **IBM Cloud Functions** 是否已停服未取得官方公告，当前主线产品是 IBM Cloud Code Engine（免费 10 万 vCPU·秒/月、单项目限 20 个函数），旧服务按「待确认」处理
- **阿里云函数计算 FC** 存在 FC 2.0 与 FC 3.0 两套并行文档树（实例并发度、最小实例数与冷启动写法不同），引用官方文档时需写明版本
- 同一产品的中国区与全球版是两套独立定价：AWS Lambda（北京 / 宁夏，仅宁夏有永久免费层）、Azure Functions（世纪互联运营）、腾讯云 SCF（中文站与国际站）均须分别引用对应域的官方页面
